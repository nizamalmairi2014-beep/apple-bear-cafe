APPLE BEAR CAFE — WEBSITE DEMO

Cara membuka:
1. Ekstrak ZIP.
2. Buka index.html di Chrome/Edge.
3. Untuk dipublikasikan, unggah ketiga file (index.html, style.css, script.js) ke layanan hosting statis.

Catatan:
- Data restoran berasal dari informasi yang diberikan pengguna.
- Menu/harga/jam dapat berubah, jadi verifikasi sebelum dipublikasikan.
- Ulasan dan foto milik pihak lain sebaiknya digunakan hanya dengan izin.
